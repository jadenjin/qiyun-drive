## 已修复问题

| 等级 | 问题 | 处理 |
| --- | --- | --- |
| 高 | 永久删除任务排队后仍可恢复，Worker 随后可能删除已经恢复的内容 | 为删除任务加入数据库所有权标记；任务成功或重试耗尽前禁止恢复，失败后释放标记 |
| 高 | 开发/构建依赖包含 16 个高危和 2 个低危公告 | 升级并重新锁定 Vinext、Vite、Cloudflare 插件、React/RSC 等依赖；生产与完整依赖扫描均为 0 |
| 中 | Go 加密模块包含一条未触达但已有修复版本的 SSH 公告 | 升级 `golang.org/x/crypto`；应用实际调用图保持 0 漏洞 |
| 高 | Go 1.26.0 标准库存在 18 个可达漏洞 | 构建和 CI 明确锁定 Go 1.26.6；同版本重新扫描后可达漏洞为 0 |
| 中 | Argon2 校验会接受数据库中的任意内存、迭代和输出长度参数 | 只接受应用生成的版本、参数和盐/摘要长度，阻止异常记录造成 CPU/内存放大 |
| 中 | 断点续传会把原始 `File` 保存在浏览器 IndexedDB，且未按账号隔离 | 续传记录绑定用户 ID，只加载当前账号记录；退出时终止上传并清空本地队列 |
| 中 | 登录时未知用户名绕过 Argon2，响应时间可能泄露用户名是否存在 | 未知用户也执行参数受限的 Argon2 校验，并继续返回统一错误 |
| 中 | 在线预览信任宽泛的客户端 MIME，可内联打开 HTML、SVG 等主动内容 | 改为显式媒体白名单；主动内容与未知类型只允许下载 |
| 中 | 分片完成参数允许重复编号、空或超长 ETag，可能放大解析与对象存储请求成本 | 限制为 1–10000 个唯一分片并约束编号、ETag 长度和控制字符 |
| 中 | 分享归档下载把短期访问令牌放在 URL 查询参数中，可能进入浏览器历史、代理和访问日志 | 归档下载改为 POST 表单提交，令牌不再进入 URL；公开分享路径在 API 日志中统一脱敏 |
| 中 | 无密码分享每次刷新都会创建新的访问令牌记录，可被匿名请求放大数据库写入 | 无密码分享直接复用高熵分享能力令牌，不再写入临时访问令牌记录 |
| 中 | 限流读取 `X-Forwarded-For` 的第一项，若代理链配置变化可能接受客户端伪造地址 | 只信任直连反向代理并读取最右侧有效转发地址；Caddy 保持默认的入站转发头清洗行为 |
| 中 | Web 运行容器默认使用 root | 改为内置 `node` 用户，Web/API/Worker 禁止提权并移除全部 Linux capabilities；媒体 Worker 使用只读根文件系统和 `noexec` 临时目录 |
| 中 | 数据库、对象存储和网关上游镜像携带可升级的系统组件，且部分服务默认以 root 启动 | 增加派生加固镜像，安装系统安全更新并以固定非 root UID 运行；Compose 增加只读根文件系统、能力移除和进程数限制 |
| 低 | ZIP 条目仅依赖写入时的文件名校验 | 输出前再次归一化路径，阻止绝对路径和父目录穿越 |
| 低 | 下载文件名编码使用查询参数转义，不完全符合 HTTP `filename*` 语义 | 改为 RFC 5987 兼容的路径百分号编码 |
| 低 | API 仅设置请求头超时 | 增加请求读取超时和 64 KiB 请求头上限 |
| 低 | 公网对象存储端点可误配为明文 HTTP | 公网主机强制 HTTPS；localhost 和私有网段仍允许 HTTP |

## 已验证的安全边界

- 会话 Cookie 为 HttpOnly、SameSite=Lax；HTTPS 配置强制 Secure。
- 状态变更接口校验精确 Origin，跨来源请求不能携带凭据读写数据。
- 空间、节点、相册和分享均在服务端重新计算权限；个人空间不会进入家庭管理员的分享治理列表。
- 分享主令牌、访问令牌、会话和重置令牌只保存哈希，并带有效期或撤销状态。
- 上传对象键由服务端 UUID 生成；文件名不能包含路径分隔符或控制字符。
- 配额预留在空间行锁内完成，上传完成仅允许一次从预留量转为已用量。
- API 与 PostgreSQL 不对局域网直接暴露；RustFS 控制台只绑定回环地址。
- 备份会暂停写入端，数据库和对象数据来自同一时间窗口并生成 SHA-256 清单。

## 部署边界与建议

当前设备使用私有局域网 HTTP，因此链路没有 TLS 保密性；这只适合可信家庭网络。若经公网、访客 Wi-Fi 或反向代理访问，必须使用 HTTPS，将 `COOKIE_SECURE` 设为 `true`，并为对象存储提供同样可信的 HTTPS 地址。

RustFS 数据端口需要供浏览器直传和预览，在设备部署中会绑定到指定局域网地址；桶保持私有，访问依赖短时签名 URL。不要将数据端口或控制台端口转发到公网。

依赖公告和容器镜像会随时间变化。每次发布仍应重新运行前后端测试、依赖扫描，并在隔离环境验证数据库迁移、上传、恢复、永久删除和分享下载。

Go 扫描仍会报告 `x/crypto/openpgp` 的 1 条模块级公告；项目没有导入该包，官方工具确认其不在应用包和符号调用图中，且上游没有可用修复版本。
